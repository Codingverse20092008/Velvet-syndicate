### 3. SQLite UPSERT Syntax Error - ON CONFLICT Clause Invalid
**File:** `lib/services/cart.service.ts:79-91`
**Severity:** CRITICAL - Cart add to cart fails completely
**Status:** FIXED

**Root Cause:** Drizzle ORM generating incorrect SQLite UPSERT syntax:
```sql
-- WRONG (generated by Drizzle):
INSERT INTO cart_items (...) 
ON CONFLICT ("cart_items"."cart_id", "cart_items"."product_id", "cart_items"."size")

-- SQLite requires:
ON CONFLICT (cart_items_unique_idx)  -- index name only
```

**Error Message:**
```
LibsqlBatchError: SQLITE_UNKNOWN: SQLite error: ON CONFLICT clause does not match any PRIMARY KEY or UNIQUE constraint
```

**Solution:** Replaced UPSERT with manual check-and-update pattern:
```typescript
const existingItem = await tx.query.cartItems.findFirst({...});
if (existingItem) {
  await tx.update(cartItems).set({ quantity: newQuantity }).where(...);
} else {
  await tx.insert(cartItems).values({...});
}
```

**Impact:** Users could not add items to cart - core e-commerce functionality broken.
